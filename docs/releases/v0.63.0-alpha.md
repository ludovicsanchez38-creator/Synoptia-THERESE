# Release v0.63.0-alpha — 31/08/2026

## Nature

Aucune PR. Deux défauts trouvés à la main par Ludo dans les heures qui ont
suivi la publication de la 0.62.0, en utilisant réellement l'application.

Bump **mineur** et non correctif : la vision est une fonctionnalité nouvelle,
pas la réparation d'un comportement existant.

## Les deux défauts

**1. THÉRÈSE ne savait pas voir.** Glisser une capture d'écran dans le chat
répondait « Type de fichier non autorisé pour l'indexation : '.png' ». Le
message pointait une liste d'extensions, mais la cause était plus profonde :
aucun chemin image n'existait dans l'application, sur aucun des seize
fournisseurs. Pas de `image_url`, pas de base64, rien. Toute pièce jointe
partait dans la chaîne d'extraction de texte.

Corrigé : `Message` porte des `ImageJointe` ; les trois formats émis
(`image_url` OpenAI, source base64 Anthropic, `inline_data` Gemini) la
transportent ; un message qui ne porte qu'une image n'est plus jeté par le
filtre des messages vides ; le composeur n'envoie plus une image à
l'indexation. Bornes dites et non subies : 5 Mo par image, 4 par tour, chaque
écart nommé.

Choix assumé : **aucune liste de modèles capables de voir**. Elle serait
fausse dans un mois. L'image est envoyée, et si le fournisseur la refuse, son
erreur remonte aux journaux (correctif de la 0.62.0). Le coût est une image
envoyée pour rien à un modèle aveugle avant l'échec.

**2. Un refus de génération ne disait rien à faire.** Dans le chat, le modèle
posait encore ses questions et déclenchait `generate_document` dans le même
tour. L'outil recevait les questions comme contenu, n'y trouvait aucun
tableau, et refusait. Le refus remontait tel quel.

C'est une arête du lot B de la 0.62.0 : meilleur qu'un classeur vide aux
colonnes A/B/C, mais incomplet. Le message dit désormais la cause **et** la
suite. La consigne n'est attachée qu'au refus de contenu insuffisant : sur
une panne technique, demander des chiffres enverrait sur une fausse piste.

## Discipline

TDD sur les deux, avec la raison du rouge **lue** et non supposée (deux
faux départs corrigés : un constructeur mal appelé, puis un jeu d'essai au
mauvais format — le parseur PPTX ne découpe que sur `---`). Sabotage vérifié
sur chaque correctif : appliqué, test rouge, restauré.
