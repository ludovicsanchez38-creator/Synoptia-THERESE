# Release v0.75.0-alpha

GO explicite de Ludo le 24/09/2026 (« Go release »), en réponse au récapitulatif
du cycle 12 qui proposait la 0.75.0-alpha. Aucune PR : les commits sont sur
`main` depuis la v0.74.1-alpha. Mode complet (fonctionnalités incluses).
