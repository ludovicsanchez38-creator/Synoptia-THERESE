## Dette de jalon actée (non bloquante, revue Soso)

- `count()` puis `delete()` Qdrant non atomiques (fenêtre théorique entre
  processus ; le verrou de chemin couvre le processus unique).
- Temporaire de copie stable orphelin si annulation PENDANT le
  `run_in_threadpool` (le thread finit d'écrire après l'annulation).
- Caractérisation du trombone légère (valeurs + inspection de source) ; son
  pipeline reste dans chat.py, sous le verrou partagé mais hors sémaphore.
- Tests de crash aux frontières SQLite/Qdrant non exhaustifs (un échec
  Qdrant et un plan en_cours simulé sont couverts ; la reprise est
  idempotente par construction).
- Avertissements React `act(...)` dans les nouveaux tests frontend à faux
  timers (verts et répétables, mais bruyants).
- Le log d'arrêt coopératif ne nomme pas la tâche asyncio individuelle.
