# Release v0.67.0-alpha - 05/09/2026

## Nature

Version issue du troisième cycle de la boucle autonome d'amélioration
(skill `boucle-amelioration-app`), lancée par Ludo le 05/09/2026 sur la
0.66.1 avec la consigne de corriger tous les bugs trouvés. Aucune PR : tout
le travail est commité directement sur `main`, en TDD, par lots fusionnés en
avance rapide depuis le worktree `repair/c3-lot1`.

Mode retenu par Ludo (GO du 05/09/2026 à 21 h 30) : release complète avec une
revue adversariale COCO (Codex CLI, `codex exec review --base v0.66.1-alpha`,
lecture seule) à la place de l'audit à trois agents, pour économiser le quota
Claude.

- Devis et factures : formulaire de devis unifié, création sous filtre, client
  hors des 200 récents, doublon au second clic, PDF (milliers, N°, délai réel,
  statut, esperluette), franchise de TVA, dates et prix hostiles (422).
- Contacts, pipeline, CRM : placeholders, adresse sous recherche active,
  historique lisible, Échap sur la modale d'activité, mode démonstration
  étanche, import (colonnes en trop, vCard), export tableur (formules, gel),
  Google Sheets, RGPD (purge réelle, secrets hors export).
- Agenda : multi-jours, tri horaire, fuseaux à l'ouest, contraste, agenda local
  par défaut, 404 propre, fin avant début, CalDAV (rappels, messages), aperçu
  sans fausses invitations, boutons nommés.
- Messagerie : assistant Gmail, IMAP (mise en route, pagination, Drafts),
  SMTP vers Envoyés, pièces jointes imbriquées, transfert HTML, 17 messages
  localisés, signature.
- Actions et agents : « Relance clients » sur les créances, résultat dans une
  vraie conversation, contextes courriels et calendrier, MCP (délai 120 s,
  écriture atomique, secrets masqués, 401/500), périmètre des agents.
- Assistante et services d'IA : plafonds de jetons, modèle hors grille, budget
  persistant, refus de sécurité, disjoncteur (B-488 puis B-579), identifiants
  d'appels d'outils, gel pendant image et dictée, champs de clés.
- Accueil, navigation, accessibilité : « Voir la suite », point d'attention
  vers la facture, palette, fermeture immédiate, une trentaine de correctifs
  a11y, lexique « Paramètres ».
- Sous le capot : socle PERT (moteur + API), protocoles XSS et multi-tenant,
  CI Windows parallélisée, cliquet mypy, garde 3 Mo.

## Revue adversariale COCO

`codex exec review --base v0.66.1-alpha` (gpt-6-astra, effort max, sandbox
lecture seule, lancé à 21 h 22, verdict à 21 h 45). Onze findings, tous relus
dans le code avant décision :

| Sévérité | Finding | Décision |
|---|---|---|
| P1 | Fermeture : le sidecar est tué dès que son port est lâché, avant la fin du nettoyage du lifespan (B-448) | VÉRIFIÉ, corrigé (`14f8d996`) : drapeau de terminaison réelle, attente bornée à 5 s, remise à zéro à la relance, garde de source `tests/test_sidecar_attend_la_fin_du_processus.py` |
| P1 | Purge globale : les cinq tables du socle PERT survivent à `DELETE /api/data/all` | VÉRIFIÉ (test rouge sur les cinq tables), corrigé (`dca1b0fd`) |
| P2 | Conditions et mode de paiement interpolés sans échappement dans le PDF | VÉRIFIÉ (ValueError sur `<b>`), corrigé (`680bdcbd`) |
| P2 | Moteur PERT : début d'une tâche calé pendant la pause (12 h au lieu de 14 h) | candidat B-581 |
| P2 | Plafonds de jetons sauvegardés chargés seulement à l'ouverture de l'onglet des limites | candidat B-582 |
| P2 | `generate_content()` court-circuite le disjoncteur quand il augmente `max_tokens` | candidat B-583 |
| P2 | Suivi d'une action figé sur « Arrêt en cours » après `cancel_requested` | candidat B-584 |
| P2 | « Réessayer » après une génération d'image échouée ne relance rien | candidat B-585 |
| P2 | Validation CalDAV qui compare les heures affichées, pas les instants | candidat B-586 |
| P2 | Renommage d'une commande sans réindexation du registre | candidat B-587 |
| P2 | Export de portabilité sans les tables de planning | candidat B-588 |

Les huit candidats restent à reproduire par la boucle (cycle 4) : l'invariant 3
du skill interdit de les fermer sur la seule lecture d'un relecteur, et aucun
n'est une perte de données ni une régression d'un parcours de la 0.66.1.

Par ailleurs, la CI de `main` était rouge sur les trois derniers commits du
cycle avant la release (ruff sur douze tests, cliquet mypy dépassé de neuf,
promesse rejetée non gérée dans un test vitest, trois tests Windows). Corrigé
dans `6bc0e813` et `d7dbe313` ; la seconde a révélé un vrai défaut, le
chargement des prestations sans `catch`, corrigé en TDD.
