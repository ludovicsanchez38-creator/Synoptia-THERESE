# Release v0.66.1-alpha - 04/09/2026

## Nature

Correctif de la 0.66.0 préparé à partir du guide de présentation, de son
backlog de recette et des vérifications menées sur un profil de démonstration.
Le lot ferme les neuf défauts encore candidats après la première passe, en plus
des dix défauts du guide déjà corrigés sur la même branche.

## Correctifs visibles

- le brief du jour se rafraîchit au retour sur l'accueil, au focus, au retour
  de visibilité et toutes les cinq minutes ;
- les factures échues et les tâches dues aujourd'hui utilisent le bon jour
  civil, dans les listes comme dans le brief ;
- le pipeline affiche tous les contacts selon leur étape et distingue de
  nouveau Signature de Livraison en thème sombre ;
- un changement de dossier de données purge les conversations, calendriers,
  comptes et brouillons conservés par le webview du profil précédent ;
- les changements de libellés Gmail vides ne provoquent plus de requête 400 ;
- une mise à jour de contact avec `stage: null` conserve l'étape existante au
  lieu de provoquer une erreur 500 ;
- la vue Fichiers respecte le dossier configuré, retire les erreurs périmées et
  confirme durablement l'indexation ;
- les résultats d'actions et les avis du Board rendent le Markdown au lieu
  d'afficher ses marqueurs ;
- le composeur ne recouvre plus les autres parcours de l'accueil ;
- la progression de l'assistant e-mail reste cohérente ;
- les PDF de devis et factures utilisent des libellés français accentués et
  des statuts traduits ;
- les notifications restent fermables au-dessus d'une modale ;
- la soumission de facture est couverte par un test déterministe.

## Hors de ce correctif

La suggestion Discord « Diagrammes & prédiction » est enregistrée séparément
en P-039. Elle demande un RFC sur le modèle de données PERT/Gantt, un moteur de

## Revue et décision

Aucune pull request n'était ouverte au pré-vol. Le lot avait déjà été intégré
sur `main` par commits fonctionnels, avec l'accord de Ludo sur les correctifs du
guide. La revue de release a donc porté sur le diff déjà intégré, les suites
complètes locales et les gates GitHub. Le contexte Codex de cette session ne
permettait pas d'agents parallèles ; les contrôles sécurité, UX, logique,
multiplateforme et packaging ont été consolidés dans la même revue.

Décision : **PUBLIER**. Aucun défaut bloquant n'a été détecté et tous les gates
de release ont réussi avant l'ouverture de la draft.

## Avertissements et dette

- L'application macOS reste signée ad hoc et non notariée ; le comportement est
  identique à la 0.66.0 et documenté dans les notes d'installation.
- La proposition P-039 « Diagrammes & prédiction » reste hors release tant
  qu'elle n'a pas été acceptée dans le portail humain.
- Le run `33878695650`, déclenché uniquement par le commit documentaire du
  rapport après publication, a été annulé par le timeout de dix minutes du job
  mypy pendant `uv sync --dev`. Le runner téléchargeait encore les dépendances
  CUDA ; mypy n'a pas démarré et aucun test n'a échoué. Le tag publié reste
  couvert par le gate de release vert et par le CI principal vert
  `33869741967`. Ce pattern d'infrastructure est consigné dans
  `docs/known-patterns.md`.
- Le premier essai Windows du run post-rapport `33878695584` a compté 3 387
  tests, un échec et aucune erreur : le harnais B-306 n'avait pas rendu la main
  après 300 secondes sur `src/backend/tests`, bien que la progression ait
  atteint 99 %. La seconde tentative du même run est verte : 3 387 tests,
  aucune défaillance, 22 ignorés. Le caractère intermittent est confirmé et
  consigné dans `docs/known-patterns.md` ; le run Windows pré-tag
  `33869741964` était déjà vert.
