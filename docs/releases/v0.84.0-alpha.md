## Ce qui change pour les testeurs

### Agenda

- Le chat reçoit l'agenda sélectionné dans le panneau. L'état de synchronisation et les erreurs de lecture sont mieux distingués.
- Un avertissement peut s'afficher lorsqu'un modèle local décrit un agenda sans l'avoir consulté. Ses critères gardent des limites.

### Mise en route

- Le résultat d'une vérification de clé reste rattaché au fournisseur d'IA qui l'a demandée, même si tu changes de fournisseur entre-temps.
- Une commande permet de relancer le moteur local après un échec de démarrage. Le parcours distingue les modèles exécutés sur ton ordinateur de ceux exécutés en ligne avec Ollama Cloud.

### Devis et factures

- Les actions rapides enregistrent le brouillon avant de changer son statut. Un formulaire modifié demande confirmation à la fermeture. Changer uniquement la facture d'origine d'un avoir compte aussi comme une modification.
- Changer le client d'un avoir retire la référence à la facture de l'ancien client. L'adresse du client est vérifiée à l'émission.
- Le PDF d'une pièce émise est protégé contre une régénération avec un profil émetteur modifié depuis. Les mentions fiscales, les pénalités et plusieurs libellés français sont corrigés. Les quantités et les prix restent identifiables sur les petits écrans.

### Export et confidentialité

- L'export couvre davantage de données et masque les identifiants de connexion dans les champs et adresses concernés. Le masquage dans le texte libre garde des limites.
- L'anonymisation signale un effacement incomplet sur le disque ou dans les données de recherche. Une restauration signale son échec si la base ne peut pas être rouverte.
- Le contexte d'une réponse e-mail est séparé par compte. La recherche de fichiers respecte le dossier et la conversation.

### Chat et messagerie

- La recherche prend aussi en compte le contenu des fichiers et prévoit une réponse prudente quand elle ne trouve rien. Si le contenu d'un fichier devient illisible, le contenu déjà utilisé pour la recherche est conservé et l'échec est signalé.
- Quand tu arrêtes une réponse, le texte enregistré correspond à celui qui a été affiché.
- Les e-mails envoyés portent leur date et leur identifiant. Les brouillons IMAP gardent le lien avec le fil et les pièces déjà fournies au moteur. Les pièces Gmail retrouvent leur nom et leur type de fichier.
- Quand le profil est indisponible, la préparation d'une réponse laisse l'identité et la signature sans valeur inventée.

### Réglages

- La comparaison des versions distingue les préversions. Une version encore inconnue ne déclenche plus de fausse annonce de mise à jour.
- Les messages sur la voix locale absente, la recherche web désactivée et les connecteurs sont plus clairs. Plusieurs commandes sont mieux nommées pour la navigation au clavier et les lecteurs d'écran. Les catégories du catalogue restent accessibles au clavier pendant une recherche.

### Installation et Windows

- Sous Linux, l'installation automatique est réservée aux distributions prises en charge. Les contrôles de fabrication et de publication écartent une destination déjà publique, une mauvaise révision ou une archive macOS d'une autre architecture.
- Sous Windows, la quantité de texte que les modèles locaux peuvent traiter était limitée à 8 192 jetons. Elle dépend désormais de la mémoire disponible mesurée par Windows et du modèle. Une solution de repli reste prévue si cette mesure échoue.
- La construction à blanc a produit un installeur Windows 64 bits signé. Les contrôles tiennent compte des modifications dues à la signature. Le code exige une signature Windows active pour publier. Des avertissements Windows restent possibles.
