# Release v0.74.1-alpha

Version de correction : fin du cycle 11 de la boucle d'amélioration (fusionné dans `main` le 23/09 sur `a8f6ec71`) et PR #96 (recherche des agents sans `grep`, sur tous les systèmes). Release menée depuis DQ SYN par Syn, sur le go de Ludo (« Go therese », « Lance la release », « Go publie »).

## Contenu

- 47 défauts répertoriés corrigés (B-948 à B-1021, dont BUG-181, BUG-182 et BUG-183 signalés par les testeurs sur Discord) et onze autres correctifs (projets, démo, accessibilité, chat, sécurité des dépendances AnyIO et Soup Sieve).
- PR #96 `fix(agents): recherche dans le code sans grep, sur tous les systèmes` : squash-merge `b152431d`. Le parcours Python remplace `grep`, qui échouait sous Windows (six tests `search_codebase` rouges dans la CI Windows). Ajoute la dépendance `regex>=2024.11.6`, déjà tirée par transformers.

## Audit de la PR #96

Mode complet (9 fichiers et une dépendance déclarée : le mode rapide ne s'applique pas). Audit lancé pendant le build, après le tag : écart à la procédure reconnu auprès de Ludo, publication conditionnée à l'absence de BLOCK.

| Agent | Verdict | Points principaux |
|---|---|---|
| Chercheur web | WARNING | `regex.compile` sans borne : `a{10000000}` alloue 2,6 Go (grep refusait le motif), régression de disponibilité ; recherche Python environ 40 fois plus lente que grep ; résultats partiels perdus au délai ; non-UTF-8 ignoré sans le dire ; pas de troncature des lignes longues ; hors diff, un nom Windows déguisé (`cle.pem::$DATA`, `cle.pem.`, nom court) passe le filtre des fichiers sensibles de `read_file`. Aucune CVE sur `regex` au-delà de 2023.8.8. |
| Expert UX | N/A | PR backend et tests uniquement. |
| Avocat du diable | WARNING | Lenteur (3,7 s contre 0,05 s sur 1,1 M de lignes), partiels jetés au délai, fichier cp1252 invisible, troncature à `max_results` non signalée, message trompeur si la racine est un fichier, syntaxe des motifs passée de BRE à Python. Confinement, délai et boucle asyncio vérifiés conformes. |

Décision (arbitre Syn) : **MERGER AVEC RÉSERVES**. Le gain sous Windows et la soixantaine de correctifs l'emportent sur des risques qui demandent un motif anormal ou un très gros dossier. Accord de Ludo : « Go publie ».
