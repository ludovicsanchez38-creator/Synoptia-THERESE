# Release THÉRÈSE v0.81.1-alpha

> Publiée le 27 octobre 2026 à 13h48 (heure de Paris), en prerelease, sur le oui de Ludo dans la salle (cartes `val-2026-10-27-12`, `val-2026-10-27-14`, `val-2026-10-27-15` et `val-2026-10-27-16`).

## Périmètre et décision

Version de sécurité issue de l'audit bêta du 27/10/2026 (huit agents, synthèse `SYNTHESE-audit-beta-therese-2026-10-27.md` hors dépôt). Les cinq points qui touchaient déjà la 0.81.0 ont été traités en cycle 21 de la boucle, Claude seul (Grok et GPT indisponibles), dans la branche `boucle/c21-securite` partie de `0b6c4fd6`. Décision de Ludo (carte `val-2026-10-27-09`) : une 0.81.1 cette semaine, le reste de l'audit en lots ensuite.

- **B-1336** (`e78251ad`) : `HoteLocalMiddleware`, middleware le plus externe, refuse toute requête HTTP ou WebSocket dont l'en-tête Host n'est pas 127.0.0.1, localhost ou ::1 (400 `HOTE_NON_AUTORISE`, fermeture 1008). Ferme le rebinding DNS vers `/api/auth/token`.
- **B-1293** (`df0a9899`) : la carte de confirmation d'envoi affiche la copie (Cc) et tout autre argument public de l'outil.
- **B-1337** (`9a48b107`) : le modèle d'embeddings se charge aux révisions auditées au cycle 15 (modèle `e9b67630`, code distant `77108403` via `code_revision`) ; un modèle personnalisé ne reçoit plus `trust_remote_code`.
- **B-1338** (`ed785df6`) : mentions de pénalités conformes à l'article L441-10 du Code de commerce (taux BCE majoré de 10 points, indemnité de 40 €, escompte : néant), dans le PDF et dans `generate_legal_mentions`.
- **B-1339** (`04a79c0c`, puis `aff7c733`) : tentative par `strip = "debuginfo"` invalidée par la CI (voir plus bas) ; sorti de la version, la recette du .deb le signale en avertissement.
- `b79920b4` : typage des ajouts (mypy revenu à 936) et test Qdrant adressé à 127.0.0.1 (le Host `testserver` est désormais refusé). `e39b255f` : montée de version.

Chaque correctif a son test de régression, vérifié en retirant le correctif pour le voir échouer, et a été rejoué sur au moins dix entrées inventées après coup.

## Contrôles

- **Portes locales** sur `b79920b4` : pytest 6 077 tests, 0 échec, 15 sautés ; moteur autonome 186 ; vitest 3 859 ; 112 parcours de bout en bout ; mypy 936, égal à la base ; ruff et tsc propres.
- **CI GitHub, premier passage** (run 40492743848, tag sur `e39b255f`) : gate complète verte, builds macOS et Windows verts, **build Linux arrêté par la recette du .deb** sur le nouveau contrôle B-1339. Cause lue dans le journal du bundler : « Failed to add bundler type to the binary: __TAURI_BUNDLE_TYPE variable not found in binary ». Le bundler du CLI 2.9.6 cherche dans la table des symboles un nom que tauri-utils 2.8.3 ne déclare pas `no_mangle` ; garder les symboles ne change rien. Le bundler 2.10.4 (CLI 2.12) cherche le texte du marqueur dans les octets.
- **Reprise** (oui de Ludo, carte `val-2026-10-27-14`) : `aff7c733` (recette en avertissement, `strip = true` rétabli), release brouillon supprimée, tag `v0.81.1-alpha` reposé.
- **CI GitHub, second passage** (run 40500195562) : gate complète verte, builds Windows x64, macOS ARM64 et Linux x64 verts, manifeste à 6 entrées sans entrée Linux générique.
- **Recette du paquet Linux** (DQ, 27/10, 13h37) : empreinte du .deb conforme au digest GitHub (`ef4aeede`), installation à la place de la 0.81.0, moteur en 0.81.1, accueil sans écran blanc, fermeture par Alt+F4 qui arrête l'application et le moteur (port 17293 libéré, aucun processus restant). Dans l'application installée : Host `piege.example` refusé (400), localhost accepté (200) ; module `modeling_hf_nomic_bert` chargé à la révision `7710840340a0`, sans téléchargement d'une version plus récente ; marqueur de paquet `VAR_UNK`, attendu. Démarrage du moteur en 32 s, deux fois ; la 0.81.0 remesurée avec le même dossier utilisateur donne 24 et 31 s : pas un effet de cette version.
