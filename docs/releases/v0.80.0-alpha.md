# Release THÉRÈSE v0.80.0-alpha

> Publiée le 23 octobre 2026 à 21:28 à Paris (19:28:08 UTC), en prerelease. Code distribué : `f3046443` (bump `7f1c1ec4` puis trois correctifs de la gate de release).

## Périmètre et décision

Cycle 19 de la boucle d'amélioration (état cycle 12 de `.app-loop`), cinq lots fusionnés dans `boucle/c19-integration` puis dans `main` par avance rapide :

- **C19-A** mémoire, recherche, chat et agenda : B-1040, B-1103, B-1104, B-1105, B-1106, B-1107, B-1044.
- **C19-B** agenda local et manifeste updater : B-1110, B-1111.
- **C19-C** migration des activités : B-1089.
- **C19-D** 47 défauts d'interface, d'accessibilité et de garde mémoire (B-1045 à B-1112), écrits par COCO.
- **C19-E** résidus de la campagne de reprise : B-1113, B-1104 (suite), B-1114, B-1115, B-1117.

Chaque lot a été relu en contradicteur par Astra (`gpt-6-astra`, lecture seule), arbitré par Syn quand un NO GO portait sur des cas hors usage réel (C19-C, C19-D). Le lot C19-E a reçu trois NO GO puis un GO (v4) après un changement d'approche sur B-1115.

**Décision de Ludo** (salle, carte `val-2026-10-23-17`, 23/10 18h07Z) : sortir la 0.80.0 maintenant, sans attendre le plateau de la boucle. Les candidats encore ouverts sont mineurs ou intermittents (voir la dette).

### Ce qui change pour les testeurs

Notes publiées sur la release GitHub (texte validé dans la salle, carte `val-2026-10-23-19`) : mémoire corrigeable par le chat, plus de faux souvenirs, recherche dans un seul document, tableaux Word, indexation sans document fantôme, heure d'hiver, messages vides, pièces trop lourdes, agenda local récurrent, une quarantaine de corrections d'interface et d'accessibilité, démarrage sur base ancienne, mise à jour Linux hors Debian, clé de signature hors du bundle.

## Incidents de la gate (premier build rouge, `7f1c1ec4`)

1. **E2E parcours 09** : B-1071 avait mis « Retour » dans le nom accessible du bouton d'en-tête et mis à jour les tests Vitest, pas le parcours Playwright (`f4b9a766`). Les portes locales de la boucle ne lancent pas les parcours de bout en bout : à ajouter avant tout tag.
2. **pytest coupé à 720 s** à 97 % (628 s pour ~4 700 tests en 0.79, ~5 350 tests en 0.80) : seuil de session porté à 18 min (`5cc520d2`).
3. **npm audit critique** sur DOMPurify ≤ 3.4.16, avis publiés après la 0.79 : passage en 3.4.17 (`f3046443`).

Correctifs poussés sur le oui de Ludo (carte `val-2026-10-23-18`), tag déplacé, aucune release ni brouillon n'existait.
