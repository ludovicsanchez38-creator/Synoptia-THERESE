### Ce qui change (détail dans les notes GitHub et le changelog Discord)

- Sécurité : navigateur interne fermé à la machine locale et au réseau privé
  (résolution DNS, revalidation de la page atteinte), neuf réponses d'erreur
  sans chemins ni jetons, recherche web coupée quand la préférence est
  illisible, résultats d'outils enveloppés dans le contexte, pixel espion à
  protocole implicite bloqué, identifiant de skill vérifié, purge d'audit à
  rétention nulle refusée, tâches rattachées au contact dans l'export RGPD.

  texte), corps vide refusé, IMAP par dossier (COPYUID au déplacement),
  filtres combinés, port « Autre », priorité nommée.
- Agenda : alias primary sans Google, plusieurs agendas annoncés, suppression
  confirmée dans l'application, message d'un 403 conservé puis effacé par un
  succès Google.
- Interface : erreurs avalées désormais dites (contacts, pipeline, limites,
  sessions, catalogue, commandes, facturer, actions externes), accessibilité
  clavier, confirmations en ligne (tâches, rendez-vous), composeur (arrêt,
  brouillon, résultat d'action, annulation), onboarding (libellés, effacement
  raté dit, un seul « plus tard »), Décision (erreur = fin, fermeture remise à
  zéro), dictée honnête, Accueil (actions perso non cliquables hors survol).
- Moteur : jetons (plafonds, zéro réel, tarifs), disjoncteur, OpenRouter,
  trame atomique et flush garde-fou, indexation, CRM Deliverables, checklist,
