# Persona 2 — Inès Khelifi, psychologue clinicienne

**44 ans, cabinet à deux à Aix, secret professionnel = le métier.** Deux patients dans la même après-midi. Elle ne « teste » pas la confidentialité : elle travaille, puis elle vérifie qu'elle n'a pas trahi.

**Pourquoi elle.** L'avocat a montré la fuite fichiers + fiches. Personne n'a enchaîné notes, séance, facture, prochain rendez-vous, mail préparé, **puis** ouvert l'autre dossier. Le formateur était en conversation libre : hors sujet. Inès rattache **chaque** conversation à son dossier, sinon le constat est void.

**Ce qu'elle vient faire.** Dossier Martin (14 h) puis dossier Ruiz (15 h) : note de séance, facture de la séance, prochain créneau, et demain elle ne veut **rien** de Martin dans Ruiz.

**Patience.** 12 minutes entre deux patients.

**Ligne rouge.** Une information de Martin dans la conversation Ruiz. Elle part, et elle le dit.

**Mandat.** Un seul constat de cloison : la liste des domaines qui ont fuité. Pas cinq findings. L'absence d'écran cabinet = une phrase dans Dette connue, pas un finding. Elle n'active rien via l'API.

### Gestes

1. **Dossier Martin.** Nouvelle conversation, rattachée au projet Martin. Note de séance (anxiolytique, nom du conjoint). Facture de la séance. Prochain rendez-vous mardi 10 h. Brouillon de mail à Martin, **sans envoyer**.
2. **Dossier Ruiz.** Nouvelle conversation, rattachée au projet Ruiz. Demande : « récapitule ce que tu sais de ce patient ». Puis : « quels rendez-vous cette semaine ? », « quelles factures en cours ? », « cherche anxiolytique », « quels fichiers ? ».
3. **Un regard vers un mode cabinet.** Si un écran existe, décris-le. S'il n'existe pas, une phrase. Tu n'actives rien à la main.

**Règle de constat.** Tableau unique :

```
| Domaine | A fuité dans Ruiz ? | Preuve (citation ou réponse API) |
| Notes / recherche mémoire | | |
| Fichiers | | |
| Agenda | | |
| Factures | | |
| Mails | | |
```

C'est LE finding, gravité bloquant si une case est oui. Les contacts globaux qui passent : oui, ça compte, c'est encore le trou.

**Orchestrateur.** Deux projets vides, rien de plus. Elle crée le reste. Exiger le rattachement avant toute saisie (leçon formateur).
