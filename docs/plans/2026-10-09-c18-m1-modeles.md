Les trois acceptent les cinq niveaux `low`, `medium`, `high`, `xhigh`, `max` (page Effort). On reprend la table déjà utilisée pour Opus 5.5. Le défaut documenté n'est pas forcé : « Auto » n'envoie rien, l'API applique le sien.

Le compteur applique le palier selon la longueur du prompt, à toute la requête. Haiku 5.5 : 0,10 / 0,50 jusqu'à 100 000 jetons de prompt compris, puis 0,50 / 2,50 au-delà (fiche Haiku 5.5). Le contrôle de budget lit ce coût.

`max_tokens` recommandé = 128 000, le plafond synchrone documenté. Les jetons de réflexion comptent dedans. Le guide Haiku dit qu'un petit plafond coupe la réponse après la réflexion. Opus 5.5 reste à 64 000 (choix antérieur, non modifié).

Ordre Anthropic : Opus 5.5 reste en tête (la fiche Fable 5.1 dit de commencer par Opus 5.5). Fable 5.1 prend la place « puissance maximale » (deuxième). Fable 5 reste juste après. Sonnet 5.5 précède Sonnet 5. Haiku 5.5 précède Haiku 4.5. Le reste ne bouge pas.

Haiku 5.5 refuse `temperature` (sauf la valeur 1), `top_p` (sauf 0,99) et tout `top_k`. Les deux ensemble sont aussi refusés. Le guide dit de les retirer. Le code n'envoie déjà ni `top_p` ni `top_k`. Il envoie encore `temperature` 0,7 : on cesse de l'envoyer pour `claude-haiku-5-5` seulement. Haiku 4.5 continue de la recevoir.

Sonnet 5.5, ruptures qui touchent le code :

- `tool_choice` `any` ou `tool` renvoie 400. `auto` et `none` passent. Le fournisseur Anthropic n'envoie pas `tool_choice`. On le vérifie, on n'en ajoute pas.
- Les blocs `thinking` sont liés au modèle et au tour. Il faut les renvoyer tels quels, y compris un bloc entre deux outils (texte vide et signature). Le rejeu du lot Opus 5.5 le fait déjà pour tout modèle. Le test de Sonnet 5.5 le verrouille.
- `thinking` `disabled` renvoie 400. On ne l'envoie pas. `between_tools` n'est pas envoyé non plus : ce n'est pas le réglage du produit.
- L'outil `computer_20251124` et l'outil advisor bêta ne sont pas utilisés ici. Rien à adapter.
- `display: "updates"` est en bêta. L'en-tête n'est pas repris. La réflexion reste masquée à l'écran, comme pour Opus 5.5.

Fable 5.1 : la fiche signale aussi le refus de l'outil forcé et des blocs de réflexion modifiés. Même rejeu, même absence de `tool_choice`. Le préfixe `claude-fable-5` retire déjà `temperature` pour `claude-fable-5-1`.

Mythos 5.1 n'est pas ajouté : accès sur vérification, hors demande.
