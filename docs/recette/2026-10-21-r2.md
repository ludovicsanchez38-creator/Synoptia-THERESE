# Recette R2 — mémoire en fiches

Seconde contradiction : **GO AVEC RÉSERVES** ; points retenus dans R2-0c. Périmètre prioritaire : noyau R2-1 à R2-5 complet avant activation. Aucun réseau sortant, fournisseur réel ni données personnelles ; processus sous seccomp et environnement reconstruit, sans clés. Données et reçus dans `.recette-r2/`.

## Preuves par point

- **R2-1** : rouge sur la base R2-0c archivée (`r2-1-rouge.xml`, import `MemoryCard` absent). Vert : neuf tests propres (version, cloisons cabinet, index chiffré, portabilité/effacements, migration idempotente, sauvegarde/restauration), huit tests contacts R1-2 conservés ; 24 tests d’estampille verts après ajout des nouvelles tables au schéma complet de leur fixture positive. L’estampille refuse une base suivie au schéma incomplet. Service non exposé avant garde/écran.

## Portes canoniques

Les premiers lancements exploratoires `avant-*` ne servent pas de référence finale : pytest a été interrompu pour figer une copie du code. La référence canonique `base-*` tourne sur l’archive Git R2-0c dans le worktree (`.recette-r2/base`), créée avant toute modification applicative, avec les dépendances déjà installées. Le même harnais `scripts/recette_r2_hors_reseau.py` lance la référence (`--baseline`) et le code courant ; seccomp interdit connect et datagrammes adressés, Ollama pointe sur `http://127.0.0.1:1`. Les tests ajoutés pour rejouer un rouge ne sont pas inclus dans la collecte initiale de référence.

Chiffres finaux : à mesurer sur code figé. Commandes : pytest `tests/ --ignore=tests/e2e` avec JUnit, suite autonome `src/backend/tests/` séparée ; Vitest ; TypeScript `tsc --noEmit` ; mypy `src/backend/app --cache-dir=/dev/null` ; Ruff `check src/backend` ; ESLint `.` depuis `src/frontend`.

- **R2-2** : rouge (`r2-2-rouge.xml`) : un mot de passe était accepté. Vert (`r2-2-vert.xml`) : cinq tests, dont le corpus fictif v1 de 30 formulations sensibles sur les trois champs, en création/édition, et quatre contre-exemples métier. Protection indépendante du type et du sujet, correction chat d’un fait, matrice global/A/B, rejeu après effacement et versions concurrentes sous `BEGIN IMMEDIATE`. Les refus n’incluent pas la valeur rejetée. Le corpus borne la preuve ; il ne garantit pas toute inférence dans toute langue.

- **R2-3** : rouge outil absent et route de reprise 404 (`r2-3-rouge.xml`, `r2-3-cache-rouge.xml`) ; vert : 28 tests pytest avec les confirmations historiques, 24 Vitest ciblés finaux (36 dans le premier périmètre cache/store/restauration), TypeScript sans erreur. HTTP/SSE écrit sans carte, garde et mémoire désactivée refusent, reçu id/version/opération durable sur la source utilisateur, y compris si le fournisseur échoue ensuite. Les pièces jointes restent dans les métadonnées. Inventaire du cache hérité : conversations/titres/dates/portées, messages et fichiers/images/sources. Reprise idempotente vers SQLCipher avant retrait de la clé, échec sans retrait, neutralisation des anciens timers et purge. Aucun nouveau texte écrit dans localStorage ; les messages locaux des autres producteurs sont synchronisés vers la base. L’envoi ordinaire garde la saisie au composeur jusqu’au premier acquittement SSE. L’écran de reçu et l’activation de l’outil restent liés à R2-5.

- **R2-4** : rouge HTTP sur la base précédente (fiche absente du payload de B), rouge budget (service absent), puis **37 tests verts** (`r2-4-final.xml`). Écriture en A puis lecture en B sur Ollama/OpenAI/Anthropic factices, flux et sans flux, capture du système et des messages convertis sans remplacer l’identité ni le sélecteur. Correction utilisateur non réécrite, effacement retiré du payload, trois sources sensibles sans rappel interconversation. Corpus lexical de neuf requêtes ; R1-1 conservé. Oracles UTF-8/outils à un octet près, document réduit avant correction/historique, quota souple, repli plus petit refusé avant construction du fournisseur. Accord revalidé sur destination/finalité effectives à chaque appel, sans accord supplémentaire sur Ollama local ou en l’absence de fiche ; identité commune hors chat sans fiches. Minimum retenu : la demande et les deux derniers messages de l’historique disponible ; le reliquat va aux faits (20 %, max. 4096), aux documents puis à l’historique supplémentaire.
