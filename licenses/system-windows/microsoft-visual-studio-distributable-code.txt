Runtime Visual C++ de Visual Studio : conditions « Distributable Code » de Microsoft
====================================================================================

Le moteur Windows de THÉRÈSE embarque, sans modification, trois fichiers du
redistribuable Visual C++ de Microsoft Visual Studio :

  msvcp140.dll     14.51.36247.0   Microsoft.VC145.CRT
  msvcp140_1.dll   14.51.36247.0   Microsoft.VC145.CRT
  vcomp140.dll     14.51.36247.0   Microsoft.VC145.OpenMP

Ils proviennent du dossier de redistribution VC\Redist\MSVC\14.51.36231\x64
de Visual Studio 18 installé sur le runner GitHub windows-latest. Leurs
empreintes SHA-256 figurent dans les entrées de ce catalogue ; la provenance
complète (chemin, version, signataire, relevé) est dans
licenses/system-windows/evidence-v0830.json des sources de THÉRÈSE.
Mention portée par les fichiers : © Microsoft Corporation. All rights reserved.

Ces fichiers sont du « Distributable Code » au sens de la section 8 des
conditions de licence de Microsoft Visual Studio Community 2026. Le dossier
[VisualStudioFolder]\VC\redist figure sur la « Distributable List » à laquelle
cette section renvoie (https://aka.ms/vs/18/redistribution, rubrique « Visual
C++ Runtime Files »). Les deux textes sont reproduits ci-dessous en version
originale, tels que Microsoft les publie, relevés le 06/11/2026 :

  https://visualstudio.microsoft.com/license-terms/vs2026-ga-community/
  https://learn.microsoft.com/en-us/visualstudio/releases/2026/redistribution
